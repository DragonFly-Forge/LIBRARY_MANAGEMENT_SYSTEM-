# Console-Based Library Management System (Kotlin)

### How to Compile and Run:
1. Ensure Kotlin compiler (`kotlinc`) is installed:
   ```bash
   kotlinc LibraryManagementSystem.kt -include-runtime -d LMS.jar
   java -jar LMS.jar
   ```
2. Or run directly with `kotlin`:
   ```bash
   kotlinc -script LibraryManagementSystem.kt
   ```
