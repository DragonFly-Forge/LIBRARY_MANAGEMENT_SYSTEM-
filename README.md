# Library Management System - Complete Assignment Package

Contains all three requested implementations divided into dedicated directories:

- `console-based/`: Kotlin terminal application implementing Tasks 1 through 7 with standard I/O and `when` expression menu.
- `web-based/`: Modern HTML5/CSS3/JavaScript responsive web portal with real-time UI, search filtering, and inventory tracking.
- `app-based/`: Native Android Mobile App built with Kotlin and Jetpack Compose (Material 3).
